## 🌪️ The Concept: Zero-Hardware Desi Room Ventilation

Commercial cooling hardware (fans, air conditioners, heat pumps) suffer from an unacceptable fatal flaw: **they require physical copper coils, moving plastic parts, and electrical wiring**.

**Jabra Fan Pro Max** eliminates hardware entirely. By modulating synthesized pink noise frequencies (140Hz – 2.8kHz) through the **Web Audio API**, Jabra Fan induces **micro-acoustic kinetic air displacement** directly from your laptop speakers. 

When your device's speakers are pointed directly at your face, the sound pressure differential simulates localized room ventilation, dropping perceived ambient temperature into sub-zero absurdity while pushing your computer's CPU to maximum thermal output.

Built specifically for a live presentation in front of **1,500 developers** at DevFest Mumbai 2026, featuring a **Zero-Scroll Widescreen Stage Cockpit**, crowd interaction triggers, and 100% Mumbai Bhidu dialect.

## 🛠️ Technologies Used

| Technology | Purpose & Implementation |
|:---|:---|
| **High-DPI HTML5 Canvas** | Custom 2D/2.5D procedural rendering engine with 2x Retina pixel density (`devicePixelRatio`), dynamic responsive viewport auto-fitting, and real-time isometric shadows. |
| **Web Audio API** | 100% procedural sound synthesis engine with zero external audio assets. Generates real-time pink noise buffers, automated low-pass biquad filtering, sub-bass FM induction motor drone (25Hz–180Hz), and stereo panning. |
| **WaveShaper Distortion** | Custom hyperbolic tangent distortion curve that activates past 9,000 RPM to simulate physical laptop speaker-cone rattle and mechanical overload. |
| **Zero Dependencies** | Pure native HTML5, CSS3, and modern Vanilla ES6+. Zero build step, zero bundlers, zero node_modules. |
| **Vercel Ready** | Configured with `vercel.json` for instant 1-click global deployment. |

## 🚀 Deployment Instructions

### Method 1: Deploy to Vercel (Recommended & Instant)

#### Option A: 1-Click via GitHub & Vercel Dashboard
1. Push this repository to your GitHub account (see Method 2 below).
2. Go to [vercel.com](https://vercel.com) and log in.
3. Click **"Add New..."** > **"Project"**.
4. Select your `jabra-fan-pro-max` repository.
5. Keep default settings (Framework Preset: **Other**).
6. Click **Deploy**! Your live link will be ready in 15 seconds (e.g., `https://jabra-fan-pro-max.vercel.app`).

#### Option B: Deploy via Vercel CLI
```bash
# Install Vercel CLI globally (if not installed)
npm install -g vercel

# Deploy directly from this directory
vercel
```
